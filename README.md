# 🐍 SNEK — Christmas Edition 🎄

A retro Snake game with festive holiday vibes, built with vanilla HTML, CSS, and JavaScript.

🎮 **[Play Online](https://gemini960114.github.io/snek-game/)**

## 🎮 Controls

- **Move**: `W` / `A` / `S` / `D` or Arrow Keys (Touch / D-Pad on mobile)
- **Pause**: `Space`
- **Restart**: `R`

## 🚀 Quick Start

Open `index.html` directly in any web browser.
